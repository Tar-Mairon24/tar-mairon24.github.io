Unidad 3: Consideraciones para el desarrollo

Descripción

Unidad enfocada en teoría de desarrollo en la nube. Se cubrieron temas como CI/CD, microservicios, conceptos básicos de Docker y buenas prácticas de software. Aunque fue una unidad corta, proporcionó la base teórica necesaria para entender cómo desarrollar aplicaciones modernas en entornos cloud.

Objetivos de la Unidad

  • Entender Docker y Kubernetes
