Unidad 2: Arquitectura de la nube

Descripción

Exploración de las tres plataformas cloud más grandes (AWS, GCP, Azure) y sus servicios principales. Se cubrieron temas como Git y GitHub para control de versiones, motores de bases de datos, el entorno LAMP, herramientas cloud de alto nivel como Kubernetes y serverless, y se realizaron las primeras prácticas con máquinas virtuales.

Objetivos de la Unidad

  • Configurar máquinas virtuales
  • Gestionar almacenamiento
  • Implementar redes virtuales

Reflexión de la Unidad

Explorar las tres plataformas fue útil para ver cómo cada una organiza sus servicios. Git y GitHub son herramientas fundamentales que ya conocía pero fue bueno reforzar. Las máquinas virtuales me recordaron por qué no me gustan, causan muchos más problemas de los que resuelven comparado con bare metal. Prefiero contenedores y Kubernetes, que es mucho más limpio.
