Resumen de Unidades

Unidad 1: Introducción y fundamentos de cómputo en la nube

Introducción a los conceptos básicos de cloud computing, incluyendo máquinas virtuales, contenedores, proveedores de nube y modelos de servicio. Se cubrieron temas como el modelo de pago por uso, tipos de servicio (IaaS, PaaS, SaaS), modelos de nube (pública, privada, híbrida), infraestructura on-premise y casos de éxito en la industria.

2 evidencias

Ver Unidad

Unidad 2: Arquitectura de la nube

Exploración de las tres plataformas cloud más grandes (AWS, GCP, Azure) y sus servicios principales. Se cubrieron temas como Git y GitHub para control de versiones, motores de bases de datos, el entorno LAMP, herramientas cloud de alto nivel como Kubernetes y serverless, y se realizaron las primeras prácticas con máquinas virtuales.

4 evidencias

Ver Unidad

Unidad 3: Consideraciones para el desarrollo

Unidad enfocada en teoría de desarrollo en la nube. Se cubrieron temas como CI/CD, microservicios, conceptos básicos de Docker y buenas prácticas de software. Aunque fue una unidad corta, proporcionó la base teórica necesaria para entender cómo desarrollar aplicaciones modernas en entornos cloud.

1 evidencia

Ver Unidad

Unidad 4: Seguridad

Unidad dedicada a seguridad en la nube. Se cubrieron normativas, casos reales de hacks, riesgos en entornos cloud, herramientas de gestión de seguridad como IAM y secret managers, amenazas comunes, técnicas de reconocimiento como Google dorks, análisis de tráfico con Wireshark, importancia de HTTPS, buenas prácticas en Linux (nunca usar root), y conceptos de white hacking. Una unidad práctica y aplicada.

6 evidencias

Ver Unidad

Unidad 5: Diseño y Desarrollo de una aplicación informática en la nube

Unidad práctica donde se aplicaron todos los conceptos vistos en las unidades anteriores. Se realizaron prácticas en Azure, se utilizó serverless para pequeñas aplicaciones, se profundizó en Docker y prácticas de contenerización. Esta unidad consolidó el aprendizaje teórico con experiencia práctica real en plataformas cloud.
