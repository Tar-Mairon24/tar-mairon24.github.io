Introducción

Este portafolio documenta el aprendizaje adquirido en el curso de Cómputo en la Nube, impartido durante el semestre enero-junio de 2026 en el TecNM Saltillo. A lo largo de cinco unidades, se exploraron conceptos fundamentales de computación en la nube, con énfasis en la plataforma Microsoft Azure.

El portafolio sirve como método de recopilación de evidencias, centralizando y recapitulando la información de todas las actividades realizadas durante el curso. Además, su desarrollo como aplicación web permite practicar habilidades de desarrollo web, integrando los conocimientos teóricos con la experiencia práctica en tecnologías cloud.

Sobre este Proyecto

El ingeniero pidió una página web para el portafolio, pero me parecía muy aburrido hacer HTML manualmente. Por eso decidí crear un generador de portafolios web que transforma un archivo YAML en un sitio web completamente renderizado.

¿Qué hace?

  • Entrada: Un único archivo portfolio.yaml con toda la información
  • Procesamiento: Valida, parsea y genera el sitio automáticamente
  • Salida: Un sitio web estático listo para desplegar
  • Características: Soporta Markdown, múltiples unidades, evidencias, adjuntos y reflexiones
  • Desarrollo: Incluye servidor de desarrollo con live reload para cambios en tiempo real
